# La Ruche — site vitrine

Site statique SEO-first pour La Ruche.

## Configuration actuelle
- Nom : La Ruche
- Invitation Discord : https://discord.gg/laruche
- URL provisoire : https://laruche.pages.dev

> L'URL `laruche.pages.dev` est utilisée comme URL canonique provisoire pour le déploiement Cloudflare Pages. Si Cloudflare attribue un autre sous-domaine ou si un domaine personnalisé est acheté, remplacer cette URL dans `canonical`, Open Graph, `sitemap.xml`, `robots.txt` et `llms.txt`.

## Déploiement
Le site peut être déployé comme site statique sur Cloudflare Pages ou un hébergeur équivalent.
